## 2. Project Title

Student Grade Calculator

---

## 3. Project Description

This program is a simple grade calculator to calculate and clasify student's grade

---

## 4. Objectives

This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives:

- The score of the task
- The score of the quiz
- The score of the midterm exam
- The score of the final exam

---

## 6. Process

The program compares the player's guess with the target number.

If the guess is:

- Too high → the program provides a "NILAI TUGAS TIDAK VALID" message
- Too low → the program provides a "NILAI TUGAS TIDAK VALID" message
- Correct → the grade and the average grading will be given

---

## 7. Output

Program harus dapat:
1. Menerima empat komponen nilai.
2. Memvalidasi nilai yang dimasukkan.
3. Menghitung nilai akhir berdasarkan bobot.
4. Menentukan nilai huruf.
5. Menampilkan hasil perhitungan.
6. Memungkinkan pengguna menghitung nilai mahasiswa lain.
